#  Student Performance Analysis Project

## Overview
This project analyzes student performance data using Python, Pandas, and SQL to identify key factors affecting academic scores.

---

##  Objective
To understand how factors like:
- Study hours
- Attendance
- Sleep time
- Parental support

impact exam performance.

---

##  Tools & Technologies
- Python (Pandas, NumPy)
- SQL
- Jupyter Notebook / VS Code
- Git & GitHub

---

##  Dataset
Student Performance Factors dataset containing academic and behavioral data of students.

---

##  Key Analysis
- Average exam score based on study hours
- Impact of attendance on performance
- Top performing students
- Correlation between lifestyle factors and scores

---

##  Insights
- Higher study hours generally improve scores
- Attendance strongly impacts academic performance
- Balanced lifestyle leads to better results

---

##  How to Run
1. Clone this repository
2. Open in VS Code
3. Run Jupyter Notebook
4. Execute all cells
